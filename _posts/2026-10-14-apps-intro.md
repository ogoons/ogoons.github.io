제가 직접 맹근 두 가지 안드로이드용 앱을 소개합니다.
코드를 대신 작성해주는 AI 에이전트 시대임에도 불구하고 코드를 열심히 깎아서 만든 앱 입니다.

이제 앱을 만드는 건 이전보다 점점 진입 장벽이 낮아지는 일이 되어가고 있습니다. 
하지만 사용자의 목소리에 기울이는 건 AI 가 대신 해주진 않습니다. 

소프트웨어의 구조를 설계하고 완성도를 올리기 위한 폴리싱 작업은 여전히 사람이 해야하는 일 입니다. 
아래에서 소개하는 앱들은 완성도를 끌어 올리기 위해 많은 시간과 공을 들였습니다.
한 번 써보시고 과감히 피드백 부탁드리겠습니다. 🙏

<h2>알고 · 자동화 앱</h2>
</div>

```
"이럴 땐 이렇게 해줘"를 직접 만들어 볼 수 있습니다.
안드로이드 OS의 개방된 정책을 옹호하는 파워 유저들을 위해 기획되고 빌드 되었습니다.
앞으로도 여러가지 기능들을 추가할 계획입니다.
```

알고는 시간, 장소, Wi-Fi, 블루투스 같은 **상황(When / If)** 을 감지해서, 화면 밝기나 볼륨, 진동, 알림 같은 **동작(Then)** 을 자동으로 실행합니다.
블록을 쌓듯 루틴을 만들 수 있어서 코딩 지식은 필요 없어요.

### 핵심 기능

- **다양한 상황 감지**: 시간, 요일과 시간, 날짜, 타이머, 장소, Wi-Fi, 블루투스, NFC 태그, 배터리 잔량
- **다양한 동작 실행**: 화면 밝기, 화면 꺼짐 시간, 볼륨, 진동, 알림 띄우기, 음성으로 읽어주기
- **조건 분기**: "If 조건이 맞으면 Then, 아니면 Else"처럼 조건에 따라 다르게 움직이는 루틴
- **루틴끼리 연결**: 다른 루틴을 켜고 끄는 것도 가능
- <span class="hue-badge"><img class="hue-white" src="{{ "/assets/images/philips-hue-light.svg" | relative_url }}" alt="필립스 휴 로고"><img class="hue-black" src="{{ "/assets/images/philips-hue-dark.svg" | relative_url }}" alt="필립스 휴 로고"></span> **스마트 조명 연동**: Philips Hue 조명의 밝기·장면 제어
- **일출·일몰 계산**: 해가 뜨고 지는 시간에 맞춰 동작

### 이럴 때 써 보세요

- **집에 도착하면**: 집 Wi-Fi에 연결되면 볼륨은 줄이고 화면 밝기는 낮춰요.
- **출근 준비**: 평일 아침 7시에 진동으로 깨우고, 음성으로 오늘 할 일을 읽어줘요.
- **해 질 무렵**: 해가 지면 화면 밝기를 낮추거나 HALO 를 통해 화면 색온도를 조절하고, 집안에 스마트 조명을 켭니다.

<h2>HALO · 밤에 쉬는 눈</h2>
</div>

```
자기 전에 폰을 보는 습관이 있다면, HALO를 한 번 써보세요! 눈을 편하게 해 줍니다.
```

HALO는 화면 위에 달빛을 연상 시키는 따뜻한 색의 필터를 얹어서 눈부심을 줄여 줍니다.
정해 둔 시간에 자동으로 켜지게 할 수도 있어요. 현재 누적 다운로드 80만 이상의 검증된 앱 입니다.

### 핵심 기능

- **야간 모드 예약**: 시작 시간과 종료 시간을 정하면 자동으로 켜지고 꺼져요.
- **필터 강도와 밝기 조절**: 내 눈에 맞게 필터를 진하게 또는 연하게 맞춰요.
- **색온도 조절**: 따뜻한 정도를 켈빈(K) 단위로 조절해요.
- **알림창에서 빠르게 켜고 끄기**: 알림창 버튼 하나로 야간 모드를 바로 바꿔요.
- **상태바와 잠금 화면에도 적용**: 원하면 알림창과 잠금 화면 위에도 필터를 씌울 수 있어요.
- **집에서만 켜기**: 지정한 장소에 있을 때만 필터가 켜지도록 설정할 수 있어요.

### 이럴 때 써 보세요

- **잠들기 전**: 밤 11시부터 아침 7시까지만 자동으로 켜 두면 신경 쓸 게 없어요.
- **밤늦게 침대에서**: 알림창에서 한 번 눌러 필터를 켜고, 밝기만 살짝 낮춰요.
- **집에서만 편하게**: 집에 있을 때만 필터가 켜지도록 해서 밖에서는 원래 화면 그대로 써요.

## 알고 × HALO · 함께 쓰면 더 편해요

> 알고 루틴에서 HALO의 야간 모드를 직접 제어할 수 있어요.

알고의 동작 목록에서 **HALO 야간 모드**를 찾아서 추가해 보세요. 시간이나 특정 루틴을 구성해서 HALO를 자동으로 켜고 끌 수 있습니다.

### 알고에서 제어 가능한 기능

- **켜기·끄기**: 야간 모드를 켜고 끌 수 있어요.
- **필터 세기**: 필터를 얼마나 진하게 할지 정해요.
- **화면 밝기**: 화면 밝기를 정해요.
- **필터 색**: HALO의 색 목록에서 골라요.

HALO 제어 기능은 모두 무료입니다.

### 이럴 때 써 보세요

- **화면이 꺼지면**: 화면이 꺼질 때 HALO 야간 모드를 자동으로 켜요.
- **아침 7시**: 매일 아침 7시에 야간 모드를 자동으로 꺼요.
- **유튜브 앱을 켰을 때**: 영상을 볼 때만 HALO 야간 모드로 전활할 수 있어요.
